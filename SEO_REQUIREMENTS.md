## 1\. FACTS ABOUT THIS PROJECT (do not re-derive, but do correct me if the code disagrees)

* Ray BodyLab is a Malaysian online shop for fitness supplements (whey protein, creatine,
zinc and similar). Customers build a basket and send the order as a WhatsApp message.
No payments, no accounts.
* Stack: React 19, TypeScript, Vite 6, react-router 7, Tailwind, Supabase (data), Vercel
(hosting, auto-deploys from `main`). It is a **client-rendered single page app**.
* Live URL: `https://ray-bodylab.pages.dev/`. `VITE\_SITE\_URL` (no trailing slash) feeds
`SITE\_URL` in `src/lib/constants.ts` and `scripts/generate-sitemap.mjs`. A custom domain
may replace the Vercel URL later, so nothing may hardcode the current domain.
* Page titles and descriptions are set by `useSeo()` in `src/lib/seo.ts` after React
mounts. `index.html` holds static defaults. Both were updated to the same wording in
commit 15.
* Public routes (confirm from `src/App.tsx`): `/`, `/catalog` (with `category`, `brand` and
`sort` query params), `/category/:slug`, `/brand/:slug`, `/product/:slug`, `/search`.
Admin routes under `/admin` must never be indexed.
* `public/sitemap.xml` is generated by hand with `npm run generate:sitemap`.
* `public/robots.txt` **currently blocks crawlers, on purpose**, until launch.
